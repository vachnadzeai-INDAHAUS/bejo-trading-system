## მნიშვნელოვანი საზღვრები

მიმდინარე ფაქტები მთავარია; ანალიტიკური აგენტები ორდერებს არ აგზავნიან. სავაჭრო გადაწყვეტილებას Chief Decision იღებს, Risk ამოწმებს დასაშვებ რისკს, ხოლო Execution ასრულებს დაშვებულ მოქმედებას. ღია პოზიცია გადაიხედება ახალი ინფორმაციის მიხედვით. Guardian მხოლოდ აკვირდება და ატყობინებს. სწავლის შედეგი მოქმედ სისტემას დამტკიცების გარეშე არ ცვლის.

საწყისი რეჟიმი არის `ENGINEERING_PAPER`; რეალური ორდერები გამორთულია. საცნობარო ტესტები არ უდრის სრული ბირჟის ინტეგრაციის ან სტრატეგიის მომგებიანობის შემოწმებას. ზუსტი სტატუსი იხილეთ სახელმძღვანელოსა და ტესტირების ანგარიშში.

## საცნობარო ტესტები

დამოკიდებულებებისა და გაშვების დეტალებისთვის გამოიყენეთ [დაწყების ინსტრუქცია](00_START_HERE.md) და [საცნობარო დამოკიდებულებები](requirements-reference.txt). ეს პაკეტი შეიცავს საცნობარო ბირთვს; სრული აპლიკაცია ასაწყობია.

## RC2-ის შენარჩუნება

ატვირთვისთვის მომზადებისას თავდაპირველი RC2 არქივის ყველა **71 ფაილი უცვლელად** შენარჩუნდა. დამატებულია მხოლოდ ეს `README.md`. თავდაპირველი `PACKAGE_MANIFEST.json` მოიცავს RC2-ის თავდაპირველ ფაილებს და არ აცხადებს, რომ ეს დამატებითი README მისი ნაწილია.

ამ მომზადებით არ იცვლება არც სავაჭრო პოლიტიკა, არც კონფიგურაცია, არც კოდი. ძველი V1/V2/V3 სამუშაო დოკუმენტები და პირადი ვიდეოები ამ პაკეტში არ არის შერეული.
